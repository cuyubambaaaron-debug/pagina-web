Cómo revisamos el código

Lo hace un programa, no una promesa. Si algo falla, la página no se publica.

  1. Lista cerrada de archivosSolo texto: .py, .js, .html, .css, .md. Ningún ejecutable ni binario.
  2. Busca secretosClaves de OpenAI, GitHub, Google, AWS, Stripe, llaves privadas y contraseñas, con el auditor de secretos, que también puedes usar tú.
  3. Busca datos privadosIPs de servidores, correos personales y rutas de nuestros equipos.
  4. Comprueba la etiquetaSi el código se conecta a un sitio o lee una clave que la etiqueta no declara, se rechaza.
  5. Firma la descargaCrea el .zip siempre igual y publica su huella SHA-256 en SHA256SUMS.txt.
