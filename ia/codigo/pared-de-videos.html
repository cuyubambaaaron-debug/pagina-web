# Pared de vídeos

La pared de móviles que se mueve en la portada de psychesai.com, lista para tu web. Solo HTML y CSS: **cero JavaScript**, cero librerías.

## Cómo se usa

1. Abre `index.html` en el navegador para verla.
2. Cambia cada recuadro por un fotograma de tus vídeos:

```
<img class="v" src="mi-video-1.webp" alt="">
```

3. Cada columna lleva su lista **dos veces**. Si cambias un vídeo, cámbialo en las dos copias: así el bucle no se nota.

## Cómo funciona

- Cada columna sube hasta la mitad exacta de su altura (`translateY(-50%)`), que es donde empieza la copia. Por eso el salto no se ve.
- La columna del medio va al revés y más lenta, para que no parezca una cinta.
- En el móvil se convierte en una fila que corre de lado.
- Si la persona pidió menos movimiento en su sistema, la pared se queda quieta.

/* Pared de vídeos: columnas de móviles que se mueven solas, sin JavaScript */
*{box-sizing:border-box}
body{margin:0;background:#0a0a0f;color:#f4f2ee;font-family:system-ui,sans-serif;overflow-x:hidden}

.portada{min-height:100vh;display:grid;grid-template-columns:1fr 1fr;align-items:center;gap:30px;padding:40px clamp(16px,5vw,72px);overflow:hidden}
.texto h1{font-size:clamp(2.6rem,6vw,5.5rem);line-height:.95;letter-spacing:-.04em;margin:0 0 20px}
.texto h1 span{color:#7aa2ff}
.texto p{color:#c9c7d2;font-size:1.1rem;max-width:30em}

/* La pared: inclinada y con los bordes difuminados */
.pared{height:120vh;margin:-10vh 0;display:grid;grid-template-columns:repeat(3,1fr);gap:16px;transform:rotate(-7deg);
  -webkit-mask:linear-gradient(transparent,#000 18%,#000 82%,transparent);mask:linear-gradient(transparent,#000 18%,#000 82%,transparent)}
.col{display:flex;flex-direction:column;gap:16px;animation:subir 60s linear infinite}
.col.sube{animation-direction:reverse;animation-duration:70s;margin-top:-30%}
@keyframes subir{to{transform:translateY(-50%)}} /* -50 %: justo la mitad, donde empieza la copia */

/* Cada vídeo. Para usar tus fotogramas, cambia el div por <img src="..." alt=""> con la misma clase */
.v{aspect-ratio:9/16;border-radius:18px;border:1px solid rgba(255,255,255,.12);box-shadow:0 20px 50px rgba(0,0,0,.5);
  display:grid;place-items:center;font:800 2rem system-ui;color:rgba(255,255,255,.7);object-fit:cover;width:100%;
  background:linear-gradient(160deg,hsl(var(--h,220) 80% 55%),hsl(calc(var(--h,220) + 40) 70% 25%))}

/* Móvil: una sola fila que corre de lado */
@media (max-width:760px){
  .portada{grid-template-columns:1fr}
  .pared{height:auto;margin:0 -16px;transform:none;display:block;
    -webkit-mask:linear-gradient(90deg,transparent,#000 10%,#000 90%,transparent);mask:linear-gradient(90deg,transparent,#000 10%,#000 90%,transparent)}
  .col{flex-direction:row;width:max-content;gap:12px;animation:lado 40s linear infinite}
  .col+.col{display:none}
  .v{width:120px}
  @keyframes lado{to{transform:translateX(-50%)}}
}

/* Si la persona pidió menos movimiento, la pared se queda quieta */
@media (prefers-reduced-motion:reduce){.col{animation:none}}
